Project Overview

About Octagon Oracle

A machine-learning system that predicts UFC fight outcomes using historical fight data, fighter statistics, and gradient-boosted decision trees.

What Is This?

Octagon Oracle is an end-to-end machine learning project that combines data science with mixed martial arts analytics. It uses the Rajeev Warrier UFC dataset from Kaggle — over 5,000 historical UFC bouts — to train a predictive model that estimates fight outcomes from pre-fight statistics.

The system encodes both fighters' career averages as a differential feature vector (Red minus Blue), which makes the prediction matchup-aware rather than treating fighters in isolation. The best-performing model is selected automatically based on AUC score and saved for use in the web application.

ML Pipeline

1
Data Loading Load preprocessed_data.csv from Kaggle UFC dataset
2
Preprocessing Filter Red/Blue outcomes, encode target variable
3
Feature Engineering Create differential features, win ratio, experience, stance matchup
4
Model Training Train Logistic Regression, Random Forest, XGBoost with 5-fold CV
5
Selection & Save Best model by AUC score is saved with joblib
6
Inference Flask app loads model and returns prediction + probability

Limitations & Disclaimer

This project is purely educational. Fight prediction is inherently uncertain — upsets happen all the time in MMA. The model cannot account for camp changes, injuries, weight cuts, psychological factors, or in-fight adaptations.

Career averages can be misleading for fighters who have significantly evolved their game, or who are early in their career with a small sample size.

Do not use this for gambling or financial decisions.
